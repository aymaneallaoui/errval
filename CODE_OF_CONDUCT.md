# Code of conduct

This is a small project maintained in spare time. The rules are short.

Be decent. Assume the person on the other side of the issue is busy, is
trying, and might be less experienced or more experienced than you. Disagree
with ideas, not with people. No harassment, no slurs, no dogpiling, no
keeping score.

If someone is making the project unpleasant to be around, tell the maintainer
through the private channels listed in `SECURITY.md`. Reports are handled
quietly. Anyone who keeps it up after a warning is removed from the project
spaces.

That is the whole policy.
